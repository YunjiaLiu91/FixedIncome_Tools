# 输入与处理口径

五个输入文件放在同一目录。CSV 第一行为字段名，支持 UTF-8 / UTF-8 BOM；日期使用 `YYYY-MM-DD`，时间必须带时区。

## 标的表 instruments.csv

| 字段 | 约定 |
|---|---|
| instrument_id / name | 唯一且非空的标的编号、展示名称 |
| asset_class / currency | `bond`、`equity`、`future`；当前只支持 CNY |
| issue_date / maturity_date | 债券起息与到期日；期货需要到期日 |
| coupon_pct / frequency | 债券年票息百分数；一年付息 1、2 或 4 次 |

## 行情表 quotes.csv

| 字段 | 约定 |
|---|---|
| record_id | 每条传入记录的唯一编号，重传也需要新编号；重复编号使整个输入失败 |
| instrument_id / vendor | 已登记标的与参数中允许的数据源 |
| asof_date | 这条行情代表的交易日期；当前不验证交易所日历 |
| published_at | 数据源发布时间，不得早于行情日期在截止时区内的零点 |
| ingested_at | 实际接收时间，不得早于发布时间 |
| bid / ask / mid | 双边数值与中间值，必须有限，bid ≤ mid ≤ ask |
| volume | 非负整数，仅作数据格式检查；不同资产的成交量不汇总 |
| quote_unit | 债券 `yield_pct` / `yield_decimal`；股票 `cny`；期货 `points` |

债券的双边字段表示收益率数值区间，不是净价买卖盘。股票是未复权价格，期间涨跌不包含分红；期货不计算合约名义金额、保证金、连续合约收益或换月影响。

例如收益率 2.04%，可写成 `2.04 + yield_pct`，也可写成 `0.0204 + yield_decimal`。输出统一为 0.0204，原始单位保留在处理记录中。标准数值舍入至 12 位小数，避免等值单位转换的浮点尾差被判成冲突；这不是交易所 tick size 约束。债券收益率暂限制在 -2% 至 30%，股票与期货价格必须为正；这些是输入合理性边界，不是交易风控限额。

## 四种处理结果

1. `rejected`：未知标的、单位错误、非法数值、时序矛盾、冲突修订等。原因和原始行号保留。
2. `not_available`：有效时序下，行情日期、发布或接收时间超过截止时点。先排除，不参与修订选择。
3. `superseded`：正常较早修订或最新版本的相同重传。
4. `accepted`：通过校验，并被选作该标的 / 日期 / 数据源的有效版本。

正常修订按“发布时间、接收时间”排序。相同时间但数值不同，整组隔离，包括旧版本，不猜测哪个版本正确。相同时间且数值完全相同，取记录编号字典序最小的一条，其他记为重传；只影响追溯编号。

非法修订先单独隔离，不替换已有合法版本。异常清单仍需运营复核：有旧版本可用，不代表新到的错误可以忽略。`accepted` 只说明当前规则通过，不保证数据真实。

## 参数 settings.json

- `cutoff`：带时区的行情截止时间；其日期必须与 `business_date` 一致。
- `vendor_priority`：有效来源的优先级，不允许空值或重复。
- `bond_gap_bp` / `price_gap_pct`：来源差异阈值。债券比较绝对收益率差，乘 10000 转成 bp；股票与期货比较相对优先来源的价格差。
- `source_review_date`：产品资料查阅日，与行情时点分开；两者不混用。
- `policy_version` / `sample_kind`：演示规则版本及数据性质。

当日展示先取最新有效日期，再按来源优先级选择，不做两路均值。只比较同一日期的来源。若最新记录不属于业务日期，显示旧日期和缺失提示，债券估值也不会使用该旧收益率。跨日变化只取同一来源有效首尾值，始末日期明确展示，不对中间缺口插值。

## 反馈表 feedback.csv

`ticket_id`、`submitted_at`、`role`、`module`、`title`、`impact`、`urgency`、`acceptance`、`evidence_ref`。

影响与紧急程度分别取 1 至 3。对模块与标题做 Unicode NFKC、空白整理和大小写归一后精确分组；不做语义相似合并。每组保留全部编号、角色、验收条件和证据引用。

优先级取组内单条反馈的最大“影响 + 紧急程度”：≥5 为 P1，3–4 为 P2，其余 P3。不把不同反馈的最高影响与最高紧急程度拼接成新分数。业务负责人需要复核该排序；本工具不自动指派或关闭工单。

## 资料表 sources.csv

`entry_id`、`product`、`asset_class`、`observed_on`、`publication_date`、`observation`、`follow_up`、`url`。链接要求 HTTPS；查阅日不得超过 `source_review_date`。没有标注发布日期就写“未标注”，不把查阅日当成发布日。
