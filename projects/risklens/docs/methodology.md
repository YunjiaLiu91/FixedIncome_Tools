# 方法与政策边界

## 历史模拟

持仓包含现金，总市值为 NAV。各资产收益先按当前市值权重合成：`r(t) = Σ w(i) × r(i,t)`。历史权重固定，因此曲线相当于每日再平衡的重建路径，不是实际历史组合。

风险使用最近 252 个工作日。令损失 `L = -r`，将 n 个损失升序排列，一日 VaR 是位置 `ceil(q × n)` 对应的损失。ES 是最差 `(1-q) × n` 个样本质量的平均损失；若不是整数，边界样本采用分数权重。重复损失不会造成尾部质量扩大。报告将负的损失风险取零，不进行平方根时间缩放。

默认 q = 97.5%。这个置信度是演示选择。Basel 市场风险框架的内部模型法使用 ES，并包含流动性期限和压力校准等要求；本项目的一日简单 ES 不实现监管资本模型，也不宣称符合 FRTB。

参考：[BCBS，2019 年市场风险最低资本要求](https://www.bis.org/bcbs/publ/d457.pdf)。

## 回测

第 t 日阈值仅由 `[t-252, t)` 的收益计算，严格排除 t 当日。实际损失严格大于 VaR 才记突破。756 日样本产生 504 个滚动预测。

Kupiec 无条件覆盖率检验比较名义突破概率与实际突破率，采用渐近卡方分布的一个自由度。零突破和全突破使用极限值处理，避免 `log(0)`。该检验不考察突破聚集，也不能单独证明模型有效。小样本、高置信度及依赖性会影响渐近近似。

## 波动与压力

协方差来自最近 252 日，年化因子为 252。资产对组合波动的 Euler 贡献为 `w(i) × (Σw)(i) / σ`，贡献合计为组合年化波动，可能出现负的对冲贡献。

债券价格变化近似 `−D_modified × Δyield`。忽略凸性、信用利差和期限结构；较大冲击时近似误差会增加。股票和黄金冲击直接作用于其持仓，现金不变。

## 演示政策

| 规则 | 检查 | 演示口径 |
|---|---|---|
| P01 | 单资产集中度 | 非现金权重 ≤ 30% |
| P02 | 行业集中度 | 非现金行业权重 ≤ 45%，分母含现金 |
| P03 | 风险预算 | 一日 VaR / NAV ≤ 2.5% |
| P04 | 流动性 | 市值 / (ADV × 10%) ≤ 5 日 |
| P05 | 估值时效 | 自然日价格年龄 ≤ 3 日 |
| O01 | 限制名单 | 名单资产买卖均需阻拦 |
| O02 | KYC | 到期日 ≥ 快照日期 |
| O03 | 适当性 | 买入的产品风险等级 ≤ 客户等级 |
| O04 | 参与率 | 单笔金额 / ADV ≤ 10% |
| O05 | 资金 / 持仓 | 买入不超过现金，卖出不超过持仓 |
| O06 | 买入后集中度 | 资产权重 ≤ 30%；减仓不被该规则阻拦 |

等于阈值视为通过。O03、O06 对卖出减仓豁免；O01 的名单限制仍然适用。实际业务中受限资产的处置可能有专门流程，这里没有实现。

所有阈值均为虚构内部政策，不是法规条款。KYC 和风险等级来自虚构订单，不代表已经完成身份识别或适当性评估。FATF 的证券行业风险导向指引可作为理解客户资料与持续监控的背景；本项目没有实现完整 AML 系统。

参考：[FATF，证券行业风险导向指引](https://www.fatf-gafi.org/content/dam/fatf-gafi/guidance/RBA-Securities-Sector.pdf)。

## 数据与审计

不填补缺失收益，不自动丢弃无行情资产，不把未知证券映射到近似产品。无效输入直接报错。估值过期作为可见政策告警保留。

证据编号是规则、版本、对象、实际值、阈值和状态的 SHA-256 摘要前 16 位，用于定位，不是数字签名。输入哈希可识别文件变化，但不能证明原始数据可信。没有实现防篡改存储、人员身份或审查流程。
