# 研究过程记录：Quality–Value–Growth 复合因子

## 实验设定

| 项目 | 设定 |
|---|---|
| 实验编号 | `demo_quality_value_growth_v1` |
| 数据频率 | 月频 |
| 样本范围 | 2016-01 至 2025-12 |
| 股票数量 | 180 |
| 样本外起点 | 2022-01-01 |
| 调仓方式 | 月末形成信号，使用下一持有期收益评价 |
| 组合方式 | 最高/最低五分位各占 50%，组内等权 |

当前实验使用模拟数据，随机种子固定为 42。模拟器在未来收益中加入了弱的质量、价值和成长信号，因此可以检查研究管线能否恢复已知关系。它不是对真实市场因子收益的估计。

## 1. 提出假设

研究从三个可解释的假设出发：盈利能力和现金流质量较好的公司可能获得更高后续收益；相对估值较低的公司可能存在估值修复；收入增长可能包含尚未完全反映在价格中的基本面信息。

没有通过全样本搜索复合权重。质量、价值和成长的权重预先固定为 50%、30% 和 20%，便于把样本外结果解释为同一信号定义的延续，而不是测试集上的重新拟合。

## 2. 定义数据时点

每条财报记录同时保存 `report_period` 和 `announce_date`。在信号日 `t`，只允许使用满足以下条件的记录：

```text
announce_date <= t
```

若同一股票存在多期已公告财报，保留公告日最近的一期。连接后再次检查 `announce_date > date` 的记录数必须为 0，并保存 `statement_age_days` 用于识别过期报表。

核心实现位于 `src/fundamental_alpha/point_in_time.py`。对应测试构造公告日前后的两个信号日，避免普通 merge 或错误日期字段引入未来信息。

## 3. 数据质量检查

每次实验在计算因子前输出 `data_quality.json`，检查：

- 财务表和行情表的行数、股票数与关键字段缺失率；
- 重复的证券—日期记录和重复财报版本；
- 公告日早于报告期的异常记录；
- PIT 对齐后的保留比例和横截面股票数；
- 公告日晚于信号日的记录数；
- 报表年龄的中位数与 95% 分位数。

本次模拟数据中，行情观测 21,600 条，PIT 对齐后保留 21,600 条，未来公告记录为 0。完整数值保存在 `outputs/demo/data_quality.json`。

## 4. 构建因子

每个月分别处理各项原始指标。先用 5 倍 MAD 去极值，再转换为截面 Z-score。三个子因子定义为：

```text
quality = mean(z(ROE), z(CFO / Assets), -z(Accruals / Assets))
value   = mean(-z(log(PE)), -z(log(PB)))
growth  = z(Revenue Growth)
```

随后将每个子因子对行业虚拟变量和对数市值做截面 OLS 回归，使用残差作为中性化后的分数。最终复合因子为：

```text
composite = 0.50 × quality + 0.30 × value + 0.20 × growth
```

处理完成后，单元测试要求每月复合因子的均值接近 0、标准差接近 1，质量因子与对数市值的相关性接近 0。

## 5. 评价顺序

评价没有从净值曲线开始，而是按以下顺序进行：

1. 月度 Rank IC，判断因子排序方向；
2. 五分组收益，检查从 Q1 到 Q5 是否大致单调；
3. 50% 最高组减 50% 最低组的多空序列（100% 总敞口）；
4. 相邻调仓期的单边换手；
5. 1、3、6 个月持有期的 IC 衰减；
6. 中性化后的行业和规模暴露；
7. 基于 10% ADV 参与率的容量代理；
8. 2022 年以后的固定样本外结果。

## 6. 本次结果

| 指标 | 结果 |
|---|---:|
| 全样本 Rank IC | 0.0698 |
| 样本内 Rank IC | 0.0696 |
| 样本外 Rank IC | 0.0701 |
| IC 为正的月份占比 | 78.3% |
| 多空月均收益 | 0.85% |
| 多空年化波动 | 2.98% |
| 月均单边换手 | 16.9% |
| 最大回撤 | -1.57% |

五分组月均收益从 Q1 到 Q5 分别为 -0.44%、0.14%、0.20%、0.36% 和 1.26%。分层方向与数据生成机制一致，样本外 IC 没有明显低于样本内。

这些结果只能说明在已知信号机制下，PIT 对齐、因子构建和评价代码能够得到预期方向。由于收益关系由模拟器设定，不能据此推断真实市场收益，也不应将当前 Sharpe 与实盘策略比较。

## 7. 结论与下一步

本次实验保留现有研究管线，下一步不继续调整模拟数据参数，而是接入小规模真实 A 股样本，优先核查公告日、财务累计口径、复权收益和历史股票池。在完成逐项抽查前，不扩展更多因子，也不根据真实测试区间优化复合权重。
