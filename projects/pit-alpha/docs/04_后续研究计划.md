# 后续研究计划

## 1. 真实数据验证

下一阶段将模拟输入替换为真实 A 股 point-in-time 数据。初始样本先控制在 30—50 只股票，逐项核查报告期、公告日、财务口径和收益起点，再扩大到完整历史股票池。数据来源、覆盖范围和许可信息会在 README 中单独披露。

主要检查项：

- 历史上市、退市和成分股记录，避免幸存者偏差；
- 财报首次披露与更正版本的时间戳；
- 累计财务指标向单季或 TTM 指标的转换；
- 复权价格、停牌、ST、新股、涨跌停和退市整理期；
- 行业分类的历史映射；
- 因子形成时间与下一可交易时点之间的间隔。

## 2. 稳健性检验

真实数据跑通后，按以下顺序增加检验：

1. 分年度和滚动窗口 IC；
2. 按行业、市值和流动性分组；
3. 牛市、熊市和高波动阶段的条件表现；
4. 去极值、中性化和股票池规则的敏感性；
5. 手续费、滑点和非线性冲击成本；
6. walk-forward 参数冻结与样本外复验。

## 3. 信号扩展

在基础财务因子通过数据质量检查后，再考虑增加分析师盈利预测修正、现金流 surprise、行业景气和财报文本变化等信号。新增信号需要先写明经济机制、字段可见时点、预期方向和失效条件，再进入回测。

## 4. 研究记录

每次实验只改变一个主要条件，并按下面的格式保存记录：

```text
实验编号 / 日期：
研究假设：
数据字段及首次可见时点：
股票池 / 样本期 / 样本外切分：
本次唯一改动：
预期结果与证伪条件：
IC / 分层 / 换手 / 衰减 / 风格暴露：
结论与下一步：
```

失败实验同样保留。这样可以追踪结论形成过程，也能减少反复查看测试集造成的隐性过拟合。
