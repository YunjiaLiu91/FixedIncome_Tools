# 真实数据接入说明

## 最小数据契约

真实数据供应商可以不同，但进入研究框架前必须整理成两张长表。

财务表每行是一家公司的一次已披露报表：

| 字段 | 含义 | 注意事项 |
|---|---|---|
| symbol | 历史证券标识 | 不要用会复用或变更后丢失的简称 |
| report_period | 报告期末 | 不是可见日期 |
| announce_date | 首次公告/版本可见日 | PIT 对齐的关键 |
| roe_ttm | TTM ROE | 明确平均净资产口径 |
| cfo_to_assets | 经营现金流/资产 | 统一单位与合并口径 |
| accruals_to_assets | (净利润-经营现金流)/资产 | 明确 TTM 或单季 |
| revenue_growth | 收入同比增速 | 避免把累计值直接当单季值 |
| pe_ttm, pb | 当时估值 | 最好用信号日行情重新计算 |

行情表每行是一只股票的一个调仓日：

| 字段 | 含义 |
|---|---|
| date | 信号形成/收盘日期 |
| symbol | 证券标识 |
| industry | 当时有效的行业分类 |
| market_cap | 当日总市值或自由流通市值 |
| adv20 | 过去 20 日平均成交额（人民币） |
| forward_return | 从下一个可交易时点开始的持有期复权收益 |

## A 股最容易踩的坑

1. **幸存者偏差**：今天的股票池回填历史会漏掉退市公司。
2. **公告日错位**：报告期、预约披露日、实际公告日不可混用。
3. **财报版本**：更正公告不能在更正前被使用；需要版本时间。
4. **累计值与单季值**：利润表和现金流量表常为年初至今累计口径。
5. **复权和收益起点**：因子在收盘后形成，就不能吃到当日收盘前收益。
6. **不可交易状态**：停牌、涨跌停、ST、新股和退市整理期需明确规则。
7. **行业历史映射**：不能拿今天的行业分类回填过去。
8. **单位与币种**：元/万元、人民币/外币、合并/母公司口径要统一。

## 推荐接入顺序

第一阶段只接入月频行情和 3—5 个财务字段，逐行抽查 10 家公司、8 个报告期，手工确认公告日前后是否正确。第二阶段加入历史股票池、交易状态和成本。第三阶段再接分析师预期、产业链或文本数据。不要一开始堆数百个字段，否则很难知道错误来自哪里。

## 真实结果的最低披露标准

- 数据供应商、样本区间、股票池和过滤规则；
- 因子定义、缺失处理、去极值、标准化和中性化口径；
- 收益起止时点、调仓频率、手续费和滑点；
- 样本内/样本外切分的确定时间，尝试过多少个变体；
- IC 均值与分年度结果、分层曲线、换手、容量和风险暴露；
- 失败实验和已知局限。
